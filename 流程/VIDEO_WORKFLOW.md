# 视频制作流程规范

版本：v03  
更新日期：2026-10-04

## 适用范围

配音、素材生成、分镜与画面制作、动画、混音、预览、渲染、验收和交付。

## 执行原则

1. 用户当次明确要求优先，包括声音、语速、画面和审批顺序
2. 接手前先核对已有文件、已确认版本和项目授权范围
3. 不擅自改写已确认文本或替换已确认配音
4. 最终配音是画面时间轴的基准
5. 先检查代表性样音，再生成全文
6. 不机械沿用旧项目的硬编码参数
7. 先制作完整可播放预览，用户批准后再渲染
8. 文件生成成功不等于验收通过
9. 不把检查脚本通过称为视觉、听感和音画同步全部通过
10. 无法试听、预览或执行检查时，明确标记未验证
11. 断点续作时继续未完成步骤，不重复生成或覆盖定稿
12. 不把某个项目的特殊效果当成所有项目的默认要求
13. 只交付真实存在、与当前确认版本一致的文件

## 执行前准备

### 项目确认

接手任务时确认：

- 项目名称
- 实际工作目录（各项目独立路径）
- 已完成阶段和产物
- 用户确认版本
- 授权范围和付费调用权限

### 必读文件

在项目目录中读取：

- `BRIEF.md` — 项目需求和目标
- `frame.md` — 画面设计和参数
- `STATUS.md` — 项目进度和版本
- `STORYBOARD.md` —（如存在）分镜详情

在本机工作区读取（如适用）：

- `MINIMAX_VOICE_GUIDE.md` — MiniMax 配音规范
- `style-references/` — 参考风格文件

若其他环境或电脑缺少规范文件，根据本规范和用户要求继续。

## 总体制作顺序

```
读规范、确认项目参数
  ↓
建立或检查项目目录
  ↓
准备配音朗读副本与发音表
  ↓
生成代表性样音并检查
  ↓
生成完整配音并验收
  ↓
冻结配音版本
  ↓
根据真实音频建立时间轴
  ↓
制作分镜与素材清单
  ↓
生成或获取图片、图标等素材
  ↓
制作画面和动画
  ↓
加入背景音乐与音效
  ↓
检查完整可播放预览
  ↓
用户批准渲染
  ↓
导出成片
  ↓
检查、交付、归档
```

图片生成和画面制作可在不依赖未确认信息时并行。不得根据估算字数制作最终时间轴。

## MiniMax 配音流程

### 前置检查

每次调用 MiniMax 前：

- 读取项目或本机 MINIMAX_VOICE_GUIDE.md

### 准备输入

- 保留展示原稿，另建朗读副本
- 朗读副本可调整标点、分段、数字和术语读法，不改变含义
- 建立项目发音表，确保术语和缩写读法一致
- 分清字母缩写和完整英文词

### 样音生成

生成约 20—30 秒代表性样音，覆盖：

- 普通陈述
- 问句或转折
- 中英文术语
- 较长句和自然收尾

声音目标：清楚、自然、有交流感，避免持续兴奋、播音腔和广告式重音

参数原则：

- 用户明确指定的声音和语速优先
- 初始参考 pitch=0、vol=1.0
- 不靠整体拉伸、提高音高或音量制造情绪
- 样音检查是内部质量步骤，用户要求试听时才交用户确认

### 完整配音生成

- 使用样音检查后选定的参数
- 按完整语义段输入，保留上下文
- 不默认逐句独立生成
- 局部重生成时保留上下文，检查拼接处
- 使用 UTF-8 读取文本和发送请求

### 配音验收

检查项：

- 漏字、重复、错读
- 数字、缩写和术语读法
- 不自然重音及句尾
- 异常静音、爆音、失真
- 段落音量差
- 拼接处的语气和音色变化

FFprobe、转写和完整解码不能代替听感验证。无法实际试听时标注未验证。

### 配音冻结

保存：

- 朗读副本和发音表
- 实际模型、音色、语速等参数
- 最终音频文件
- 去除敏感信息的生成记录
- 字幕或时间戳文件
- 真实时长
- 检查记录

配音时长变化后重新校准画面和音效。

## MiniMax 接口参数（参考）

接口：`POST https://api.minimaxi.com/v1/t2a_v2`

历史参数示例（不是必用值）：
- model: speech-2.8-hd
- voice_id: KeYun001
- speed: 1.2
- vol: 1.0
- pitch: 0
- language_boost: Chinese
- format: mp3
- subtitle_enable: true

接口更新时优先核对最新文档。

## 图片素材

### 提示词文件格式

单张使用 TXT，批量使用 JSONL。

提示词应明确：
- 用途
- 主体及动作
- 主体位置
- 后期文字留白
- 构图和比例
- 色调、光线、材质
- 景深或透明背景要求
- 禁止出现的文字、Logo、水印
- 输出文件名和版本

### 图片检查与接入

生成后分两步检查：

原图检查：
- 主体、手部、物体结构是否正常
- 构图、留白、光线和景深是否符合要求
- 文字、Logo、水印是否意外出现
- 文件能否打开，尺寸是否正确
- 透明图片是否具有真实 alpha 通道

合成后检查：
- 裁切是否合理
- 标题是否遮挡主体
- 画面是否清晰
- 动画中是否出界或缺图
- 是否引用最新版本

完整流程：确定用途 → 写提示词 → 加载配置 → 执行生成 → 保存至 assets/images → 检查原图 → 接入源脚本 → 重新构建 → 截取实际画面 → 检查合成 → 更新索引

替换素材后需重新检查，并按批准情况重新渲染。

## 音频时间轴

每段至少记录：

- 片段编号
- 音频开始时间（秒）
- 音频结束时间（秒）
- 对应场景或内容
- 元素入场时间
- 镜头转场时间
- 音效触发时间

句级时间戳用于划分场景。精确跟随某个词的元素必须进一步校准。不能把句级时间戳称为逐词同步。

## 画面和动画

- 常用 HyperFrames 制作，GSAP 编排动画
- 保持可重复定位的主时间轴
- 支持暂停、跳转和反向定位检查
- 随机效果固定种子或结果
- 字体、图片、音频保存到项目本地
- 检查入场、停留、转场和离场
- 保持源脚本与生成文件一致
- 不只修改生成文件而遗漏源脚本
- 不把静态截图当作完整动画预览

## 混音

- 配音优先
- BGM 参考增益 0.18—0.22，按实际响度调整
- 增益不是固定响度标准
- 音乐开头和结尾淡入淡出
- 必要时避让人声频段
- 音效与真实动作对齐，长度匹配动作持续时间
- 不为每个元素添加音效
- 不擅自改变已确认配音的速度和断句
- 检查整片混音，不只检查独立音轨

## 默认输出规格

除非用户或项目另有要求：

- 分辨率：1080×1920（9:16）
- 帧率：30 fps
- 封面：位于开头，恰好一帧
- 安全边距：左右关键内容 ≥64 px，顶部标题 ≥120 px，底部 ≥250 px
- 格式：MP4
- 视频编码：H.264
- 音频编码：AAC

## 预览验收

渲染前逐项检查：

1. 每幕截图：字号、层级、裁切、遮挡和图形关系
2. 完整动态预览：镜头、动画和音画衔接
3. 图片、字体、音频加载正常
4. 无不明空白、闪帧或重复入场
5. 配音清楚，音乐和音效不过量
6. HyperFrames 错误和警告按适用规范处理
7. 实际确认预览链接可访问
8. 用户已明确批准渲染

技术检查通过不能代替视觉、听感验收。不新增用户没有要求且规范没有规定的审批关卡。

## 渲染与成片验收

### 渲染执行

- 使用用户确认的最新版本
- 输出到 `renders/` 目录
- 不覆盖旧成片
- 记录失败、回退及未完成项

### 成片检查

导出后执行：

- FFprobe 核对分辨率、帧率、编码、音轨和时长
- 完整解码检查
- 抽查首帧、关键转场、修改位置和结尾
- 检查成片音画同步与混音
- 核对实际交付路径
- 明确没有完成的检查
- 更新项目状态与 OUTPUTS.md

## 文件组织

### 项目目录结构

```
videos/<项目名>/
├─ BRIEF.md
├─ frame.md
├─ STORYBOARD.md
├─ STATUS.md
├─ index.html
├─ scripts/
├─ assets/
│  ├─ audio/
│  ├─ images/
│  └─ fonts/
├─ previews/
└─ renders/
```

### 文件命名

`<项目名>-<用途>-v01.<扩展名>`

- `scripts/` — 制作、调用、处理和验证脚本
- `assets/audio/` — 配音、样音、音乐、音效和时间戳
- `assets/images/` — 图片、图标、Logo 及相关提示词
- `previews/` — 截图、预览材料和检查结果
- `renders/` — 最终成片

保留已确认旧版本。新建项目或交付成片后更新根目录 OUTPUTS.md。

## 其他环境接手检查清单

若在其他电脑或 AI 环境接手，先确认：

- [ ] 是否同一台电脑
- [ ] 项目工作目录是否存在
- [ ] 是否有读写权限
- [ ] 是否允许联网和执行已授权的付费调用
- [ ] Python、Node.js、FFmpeg、FFprobe 是否可用
- [ ] HyperFrames 和浏览器是否可用
- [ ] 哪些阶段和产物已获用户确认

注意：
- 不能假设本机绝对路径在其他电脑仍然有效
- 缺少工具时先查找已有安装
